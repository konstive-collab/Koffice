# Koffice Fusion v0.11 — перенос между редакторами

**Это локальный перенос данных с помощью настоящих движков Koffice, а не автоматическая синхронизация и не полная поддержка форматов Microsoft Office.**

## Writer → Sheets

Открой документ Writer со встроенной таблицей Sheets и нажми **To Sheets** на объекте. Лист добавится к уже открытой книге Sheets. Исходные ячейки, формулы и адреса сохраняются целиком, включая диапазоны за пределами видимого фрагмента. Остальные листы книги остаются на месте. При совпадении названий автоматически создаётся имя вида `Sheet 1 (2)`.

После переноса книга Sheets помечается как несохранённая: для записи на диск нажми **Save**. Исходный документ Writer и его встроенная таблица не изменяются. Ошибочная операция или конфликт ревизий не должны частично менять книгу.

## Base → Slides

В Base выбери таблицу и нажми **To Slides**. В презентацию добавится новый слайд — текстовый снимок первых 20 строк и восьми столбцов первой страницы базы. Прежние слайды не удаляются. Если данные обрезаны, появится предупреждение, а в заметках будет указано, что это статический снимок, **не живая связь с базой**.

Изменение записей в Base не обновляет созданный слайд автоматически. Для нового актуального снимка нужно повторить действие. После переноса сохрани презентацию.

## Проверки и ограничения

Добавлены Rust-тесты на сохранность формул и Unicode, уникальные имена листов, ошибочную ревизию, атомарность изменений и ограничения вывода Base. Дополнены тесты подключения команд к интерфейсу.

Следующие крупные этапы: живые связи и граф зависимостей, обновление данных с разрешением конфликтов, таблицы и диаграммы в Slides, вставка объектов по курсору Writer, сквозной Undo/Redo и тесты производительности на Windows/Linux/macOS.
