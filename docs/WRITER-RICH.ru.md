# Kodi Writer 0.19 — первый этап форматированного редактора

Writer больше не ограничен обычным текстовым полем с символами Markdown. Теперь текст форматируется непосредственно на странице, а оформление сохраняется в родном `.kdoc`.

## Что можно сделать

Выдели текст и используй панель форматирования: **жирный**, *курсив*, подчёркивание, зачёркивание, заголовок 1/2, обычный абзац, цитату, маркированный и нумерованный список. Можно вставить базовую редактируемую таблицу 2×3, горизонтальную линию и дату.

Для действий непосредственно в редакторе работают Undo/Redo и системные сочетания клавиш. Форматирование сохраняется в `.kdoc`, выводится в HTML и при печати. Встроенные таблицы Fusion продолжают сохраняться отдельно, с исходными формулами.

## Совместимость

Поле `rich_html` необязательное. Старые документы, содержащие только `text`, превращаются в обычные абзацы при открытии, не меняя исходный формат. Если более старый API или автоматизация изменяет текст через ReplaceAll/Insert/Delete, устаревшее форматирование очищается вместо некорректного переноса на другие символы.

## Безопасность

Входящий HTML очищается: удаляются активные элементы и все атрибуты, включая обработчики событий. В Rust добавлены проверка опасного содержимого и ограничение размера. Внешние изображения, CSS, ссылки и скрипты не загружаются из документа.

## Чего пока нет

Важно: это пока **не полноценный аналог Microsoft Word/LibreOffice Writer**. Нет DOCX/ODT, настоящей автоматической разбивки на страницы, настройки полей, колонтитулов, изображений, сложных таблиц, сносок, рецензирования и полноценной истории отмены между документами.

Редактирование работает в одной растущей области страницы. Встроенные таблицы Sheets пока располагаются после основного текста, а не в произвольном месте курсора. Результат требуется проверить вручную на Windows, Linux и macOS.
