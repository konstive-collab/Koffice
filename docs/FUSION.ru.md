# Koffice Fusion v0.10 — таблицы Sheets внутри Writer

**Статус:** экспериментальная альфа-версия, первый работающий шаг по интеграции редакторов. Пока это не аналог Microsoft OLE и не система живых связей между файлами.

## Как пользоваться

Открой Writer и нажми **Insert Sheets table**. При подтверждении будет создана независимая копия активного листа Sheets, при отмене — пустая таблица. Таблица появится под текстом документа. Нажми **Edit**, чтобы открыть сетку Sheets непосредственно в Writer.

Редактирование и вставка нескольких ячеек из буфера используют тот же Rust-движок, что обычный Sheets. Формулы сохраняются как формулы, а не превращаются в изображения. Через кнопку **Go to cell** можно перейти к любой ячейке A1–ZZ10000; редактор показывает ограниченный фрагмент сетки, чтобы не загружать всё сразу.

При сохранении Writer таблица целиком записывается **внутрь .kdoc**. Исходная рабочая книга Sheets при этом не изменяется. Старые документы .kdoc без нового поля встроенных объектов продолжают открываться.

## Безопасность и целостность

- До 12 встроенных объектов на один документ и 25 000 заполненных ячеек суммарно.
- Валидация структуры, адресов, формул как текста и идентификаторов объектов.
- Проверка ревизии; изменение пакета ячеек либо полностью проходит, либо не изменяет документ.
- Rust-тесты на сохранение/повторное открытие, формулы, откат при ошибке и старые форматы документов.

## Что пока не сделано

Таблицы размещаются **после основного текста**, не в произвольной позиции курсора. Их ячеечная модель работает через Sheets, но полноценного набора инструментов оформления, графиков и фильтров непосредственно во встроенной панели ещё нет. Нет синхронизации с исходным файлом, связанной базы Base в Slides, общего Undo/Redo и настоящей совместимости с XLSX/DOCX.

Следующая итерация: привязки к позициям текста, связи между документами с управлением конфликтами, общее отображение диаграмм, связь Base → Slides и тесты производительности на Windows/Linux/macOS.
