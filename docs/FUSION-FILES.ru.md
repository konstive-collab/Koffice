# Koffice Fusion v0.13 — постоянные связи с файлами Sheets

Теперь Writer умеет сохранять внутри `.kdoc` ссылку на **реальный файл `.ksheet`**. После перезапуска Koffice таблицу можно проверять и обновлять из файла без повторного ручного копирования. Это первая реализация *постоянных файловых связей*, но не фоновая автоматическая синхронизация.

## Работа со связью

1. Открой Writer, нажми **Link Sheets file**, выбери файл `.ksheet` в системном диалоге, затем номер нужного листа и название таблицы.
2. Writer хранит весь встроенный лист (включая формулы), а также путь к файлу и информацию об источнике. Сохрани документ `.kdoc`.
3. После изменения исходной книги и её сохранения нажми **Check file**. Koffice покажет полный путь и запросит подтверждение чтения. Возможные состояния: `current` (актуально), `changed` (источник изменён), `conflict` (локальные изменения в Writer), `disconnected` (файл отсутствует либо источник не совпадает).
4. **Refresh file** позволяет обновить таблицу из сохранённого файла после подтверждения. Если внутри Writer таблица редактировалась, операция заблокируется и не затрёт правки. Затем сохрани Writer.
5. При переносе исходного файла используй **Relink file** — повторный выбор через системный диалог. **Detach file** удаляет связь без удаления данных и формул.

**Безопасность:** простое открытие документа `.kdoc` не вызывает чтение внешних файлов. Чтение сохранённого пути выполняется только после явного подтверждения пользователя. Исходный файл не изменяется этими действиями.

## Важные ограничения

Путь хранится абсолютным. При переносе документов на другой компьютер связь может потребовать Relink file; сама таблица продолжит отображаться из встроенного снимка. Сейчас нет автоматического отслеживания файлов, облачной синхронизации, массового обновления зависимостей, алгоритма объединения конфликтующих правок и полной совместимости с Excel.

Добавлены тесты Rust на реальную запись и повторное чтение связей, изменения формул, отсутствие исходного файла, корректность переподключения и запрет перезаписи локальных правок. Проверки Windows/Linux/macOS выполняются в GitHub Actions.
