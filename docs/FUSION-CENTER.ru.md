# Koffice Fusion v0.14 — Центр управления связями

В Koffice появилась панель **Fusion links** для контроля встроенных и связанных таблиц внутри Writer.

## Как пользоваться

1. Нажми **Fusion links** в верхней панели. Откроется список объектов текущего Writer: независимые, связанные с текущей сессией Sheets и связанные с файлами `.ksheet`. **Простой просмотр списка не читает файлы на диске.**
2. Отметь необходимые файловые связи и нажми **Preview selected files**. Программа покажет пути к файлам, которые собирается прочитать, и запросит подтверждение.
3. Просмотри результаты: `current` (данные совпадают), `changed` (есть изменения), `conflict` (локальные правки в Writer), `disconnected` (источник недоступен). Для изменённых таблиц показываются число отличающихся ячеек и до восьми примеров адрес/было/стало.
4. Нажми **Apply changes atomically** и подтверди обновление. Rust повторно проверит **все** исходные файлы. Если один из них изменился после предпросмотра или изменился документ Writer, обновление целиком отменяется. Частично обновлённых таблиц не останется.
5. Нажми **Save** в Writer, чтобы изменения записались в `.kdoc`. Сами исходные `.ksheet` не меняются.

Если в предпросмотре есть конфликтные или отключённые объекты, кнопку Apply нельзя нажать. Сними их выделение либо исправь связь, затем выполни Preview заново.

## Архитектура

- Новый модуль Rust `fusion_manager.rs`: список связей, предпросмотр отличий и атомарное применение.
- Предпросмотр имеет одноразовый токен и привязан к ревизии документа. Файлы сверяются повторно по фактическим данным листов и версии источника, а не только по дате изменения.
- При ошибке всё изменение откатывается; локальные правки в Writer защищены.
- Список ограничен 12 объектами на документ, примеры изменений — восемью на таблицу.
- Существующие файлы `.kdoc`, обычные встроенные Sheets и связи прошлых версий продолжают поддерживаться.

**Ограничения:** пакетное обновление пока работает только с файловыми связями Sheets → Writer. Для связей с текущей сессией Sheets доступны индивидуальные команды Writer. Автоматической синхронизации, общего Undo/Redo, живых диаграмм Base → Slides и объединения конфликтов пока нет.
